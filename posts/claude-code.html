负基础 Claude Code 安装使用教程

KANIN· 约 5 分钟· 微信公众号首发

Claude Code 是 Anthropic 推出的AI 编程代理，它不仅是传统的代码补全工具或聊天助手，而是一个能够在终端、桌面应用和 IDE 中自主运行的命令行代理——可以读取代码库、编辑文件、执行命令，并在执行可能具有破坏性的操作前请求确认。

它的独特之处在于代理循环的工作机制：当你交给它一个任务时，它会自主经历「收集上下文 → 采取行动 → 验证结果」的循环，将数十个操作链接在一起并根据中间结果不断调整。这意味着它不是被动地回答你的问题，而是主动地替你完成编码任务。

Claude Code 于 2025 年 2 月首次亮相，如今已成为 Anthropic 最重要的 AI Agent 样板之一，被用来证明「AI 可以进入真实工作现场」的核心产品。

安装node.js

a. 去Node.js — 下载 Node.js®点击“Windows安装程序”下载安装包

b. 打开下载好的安装包，一路下一步即可！

安装claude code

a. 按win + r 打开运行对话框，输入powershell按回车打开终端

b. 在终端中输入如下指令：

npm install -g @anthropic-ai/claude-code

c. 出现如上图所示提示及代表安装成功，关掉当前powershell终端

提示：使用npm安装会出现powershell不能调用claude，但是cmd可以使用的情况，配置完成之后可以让claude自行修复

按win + r打开运行对话框，输入cmd按回车打开终端，在终端中输入claude即可打开claude code。但是现在没有配置api key，所以会报错

配置api key：

a. 打开如下目录C:\Users\你的用户名\.claude新建文本文件并命名为settings.json(需要打开文件扩展名)

b. 使用你的文本编辑器打开，这里使用记事本打开，在里面粘贴如下内容：

{
  "env": {
    "ANTHROPIC_BASE_URL": "基础URL",
    "ANTHROPIC_AUTH_TOKEN": "API_KEY",
    "ANTHROPIC_MODEL": "模型ID",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "模型ID",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "模型ID",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "模型ID"
  }
}

c. ctrl + s保存，关闭记事本

注意：如果你没有API KEY可以去Xiaomi Mimo注册一个mimo，填写如下邀请码可以获得10元的额度YZDEVH
