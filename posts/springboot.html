SpringBoot 项目初始化

KANIN· 约 8 分钟· 微信公众号首发

创建项目

  1. 点击“文件-新建-项目”。打开新建项目对话框

  1. 在打开的新建项目对话框中单机左侧项目类型中的SpringBoot 创建SpringBootd项目

  1. 内容解释：
    1. 语言：选择java
    2. 类型：指的是包管理器类型，web项目一般选择maven
    3. 组：一般是公司与名反写比如：com.wfit
    4. 工件：通常是项目名称
    5. 软件包名称：公司域名反写+包名
    6. JDK：根据实际需求，这里我们选择“openJDK 17.0.12”
    7. java：大版本和JDK保持一致
    8. 打包：jar

填写完成后单击下一步

  1. 这里是选择java依赖，把SprungBoot版本改为3.5.13，我们勾选一下项：
    1. Spring Web
    2. MySQL Driver
    3. Lombok

单击创建

  1. 主要文件及文件夹介绍：
    1. .idea: idea生成的文件夹，用于保存idea的配置信息
    2. .mvn：maven的文件夹存放了maven的部分配置
    3. src：代码存放文件夹
    4. pom.xml: 项目的基本信息和依赖坐标
  2. 改造application.properties文件：

将application.propertie重命名为application.yml，并且讲原本内容改为：

spring:
  application:
    name: dome
  1. 手动导入一些必备依赖：
    1. MyBatisPlus：
<dependency>
            <groupId>com.baomidou</groupId>
            <artifactId>mybatis-plus-spring-boot3-starter</artifactId>
            <version>3.5.15</version>
        </dependency>

在 application.yml 配置文件中添加 H2 数据库的相关配置：

# DataSource Config

spring:

  datasource:

    driver-class-name: org.h2.Driver

    username: root

    password: test

  sql:

    init:

      schema-locations: classpath:db/schema-h2.sql

      data-locations: classpath:db/data-h2.sql

在 Spring Boot 启动类中添加 @MapperScan 注解，扫描 Mapper 文件夹：

@SpringBootApplication

@MapperScan("com.baomidou.mybatisplus.samples.quickstart.mapper")

public class Application {
    public static void main(String[] args) {

        SpringApplication.run(Application.class, args);

    }




}

        </dependency>
