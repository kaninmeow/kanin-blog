是一个超链接标签 其中里面有两个常见的属性：

href 表示链接地址

css的引入方式

行内样式：写在标签的style属性中 配合javascript使用

使用标签包裹起来 这个标签是没有任何意义的只是将内容包裹起来 在里面使用style属性指定字题颜色

2025年1月1日

内部样式：写在style标签中 （可以写在页面任何位置 但是通常写在head中）

<html>
    <head>
        <title>HELLO HTML</title>
        <style>
            span{
                color:red; 
            }
        </style>
    </head>
    <body>
        <h1>【学习新思想 整座新青年】</h1>
        <a href = "cctv.com" target="_blank">央视网</a>
        <span>2025年1月1日</span>
    </body>
</html>

外部样式：写在一个单独的.css文件中 通过link标签在网页中引入

link标签中的两个属性

rel：引入的样式

href：表示引入的地址

可以使用text-decoration:none标签去除超链接下面的下划线

CSS选择器

CSS选择器书用来选取需要设置样式的元素（标签）的

<html>
    <head>
        <title>HELLO HTML</title>
        <style>
            span1{
                color:red; 
            }
            .cla {
                color:blue;
                size : 500px;
            }
            #id {
                color:green;
            }
        </style>
        <link rel="stylesheet" href="img\css\news.css">
    </head>
    <body>
        <h1>【学习新思想 整座新青年】</h1>
        <a href = "cctv.com" target="_blank">央视网</a>
        <span1>我是元素选择器</span1>
        <span .clss = "cla">我是类选择器</span>
        <span id = "id">我是id选择器</span>
    </body>
</html>

三种选择器的优先级：

盒子模型

页面中所有的元素 都可以看作一个盒子 由盒子将页面中的元素包含在一个矩形区域内 通过盒子的视角更方便的进行页面布局

盒子模型组成： 内容区域(content)、内边距区域(padding)、边框区域(border)、边外据区域(margin

)

布局标签：网页开发中 会使用div和span这两个没有语义的布局标签

div标签

一行显示一个

宽度默认是父元素的宽度 高度由内容撑开

可以设置宽高

span标签

一行可以显示多个

宽度和高度默认由内容撑开

不可以设置宽高

div {
    width : 200px;/*设置宽度*/
    heigth : 200;/*设置高度*/
    background-color : #05a012d; 设置背景色
    padding : 20px 20px 20px 20px; 内边距
    border : 20px solid #a23222;边框
    margin : 20px 20px 20px 20px;外边距
    /*方位分别是上右下左 顺时针*/
}
